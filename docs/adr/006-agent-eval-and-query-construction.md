# ADR 006: Independent Agent Eval and source-bounded Query construction

Date: 2026-08-29
Status: accepted for the local Stage 5 slice

## Context

The stage-aware retrieval Runtime can branch, call bounded tools and publish a
Replay-validated Trace. A successful demo path does not prove that it handles
alternative outcomes, failures, budget exhaustion or adversarial Planner
decisions correctly. The project also needs more Query shapes for Bad Case
discovery, but the Owner learning gate still locks the larger dev profile and
the frozen test cannot be used for tuning.

## Decision

Build two separate capabilities:

1. A fixed 12-task Agent Evaluation Harness whose expected outcomes are static
   Suite data, not generated by the production Planner. One task anchors the
   real smoke path; isolated strict fixtures make failure branches repeatable.
2. A deterministic Query constructor that reads only committed smoke Query and
   provenance columns. Synthetic variants remain unjudged development cases and
   cannot enter formal search metrics.

Deterministic Agent evidence is separated from the dynamic execution receipt.
The CLI and authenticated API accept only fixed Suite/source identifiers. Both
capabilities produce private immutable artifacts and privacy-safe aggregate
summaries. Neither receives proposal approval, strategy activation, network,
model or arbitrary filesystem authority.

## Alternatives rejected

- Reusing the production Planner to generate Oracle answers: circular and unable
  to detect a shared logic error.
- Using only one happy-path demo: does not test recovery, containment or Replay.
- Letting an LLM judge be the sole evaluator: non-deterministic and not reliable
  enough for authorization or safety assertions.
- Opening the 500-Query dev or frozen test to get more inputs: violates the
  existing learning and contamination boundaries.
- Copying ESCI labels from an original Query to its synthetic variants: the user
  intent and relevance set may change, so inherited labels would be false truth.

## Consequences

The project can now quantify Agent behavior separately from search quality and
can create more exploratory Query shapes without claiming new relevance labels.
The v1 score remains limited by scripted failures, a terminal-grounding proxy and
the absence of a force-terminating worker deadline. A model Planner, larger data
profile and browser approval remain separate future decisions.
